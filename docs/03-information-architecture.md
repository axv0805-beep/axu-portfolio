# 03 · 信息架构与页面清单

## 1. 站点地图

```
/                          首页
├── /works                 作品总览（?type=分类&page=页码）
│   └── /works/[slug]      作品详情
├── /about                 关于
├── /admin                 后台（需登录）
│   ├── /admin/login
│   ├── /admin              概览
│   ├── /admin/works        作品列表
│   │   ├── /admin/works/new
│   │   └── /admin/works/[id]
│   ├── /admin/categories   分类管理
│   ├── /admin/media        媒体库（P1）
│   ├── /admin/profile      个人资料
│   ├── /admin/settings     站点设置
│   └── /admin/account      账号安全
├── /sitemap.xml
├── /robots.txt
├── /404                    未找到
└── /500                    服务错误
```

**为什么分类页用查询参数而不是独立路由**：作品列表与分类页共享同一套网格、筛选、分页逻辑，`/works?type=ai-painting` 只替换页头（分类名 + 描述）与数据过滤条件，避免两套代码与两套 SEO 规则；URL 可分享、可被收录，canonical 指向自身。若未来需要独立运营的分类落地页，可将 `/works?type=x` 301 到 `/works/x`，数据层不变（见 11 号文档）。

## 2. 导航模型

### 2.1 顶部导航（前台）

| 位置 | 内容 | 行为 |
| --- | --- | --- |
| 左 | 册页线 Logo + 站点名「留白集」 | 回首页 |
| 中 | 首页 / 作品 / 关于 | 当前项下方 1 px 陶土色下划线 |
| 中·下拉 | 悬停或聚焦「作品」展开分类菜单：全部作品 + 6 个分类（含作品数） | 点击进入对应列表；Esc 关闭；键盘可操作 |
| 右 | 「联系」文字链接 | `mailto:`，无独立页面 |
| 右·移动端 | 菜单按钮 | 全屏抽屉，见 05 文档 |

导航项显隐由 `settings.nav` 控制，但「作品」始终保留。默认顺序：首页、作品、关于。

### 2.2 后台导航

侧栏固定 240 px，顺序：概览、作品、分类、媒体（P1）、个人资料、站点设置；底部：账号安全、退出登录。当前项左侧 2 px 陶土色刻度 + 浅色底。

### 2.3 页脚

深色区块，含：大号邮箱、导航复列、社交链接、版权与备案号。后台不显示前台页脚。

## 4. 内容层级

```
Site Profile（单例）
└── Categories（1–8 个展示分类）
    └── Works（每类 N 件）
        ├── 元信息（标题/年份/工具/标签/角色）
        └── Blocks（有序内容块）
              ├── 文本类：paragraph / heading / quote / prompt
              ├── 媒体类：image / gallery / video / audio
              └── 其他：link / divider
Media Library（被 Blocks 与封面引用）
Settings（全站配置）
```

一条内容只能有一个归属分类；标签可跨分类。首页「精选」是作品的布尔标记，不单独建集合。

## 5. 关键用户流程

### 5.1 访客：从首页到作品

```
首页 Hero（是谁）
  → 目录（有什么类型）
  → 选择「AI 原画」
  → 列表（浏览封面）
  → 详情（看作品与制作过程）
  → 上一件/下一件（继续浏览）
  → 页脚邮箱（联系）
```

设计约束：任何一步都能 1 次点击回到「作品」或「首页」；详情页不出现弹窗、不被登录打断。

### 5.2 访客：按类型直达

外部链接 `/works?type=ai-video` → 页头显示「AI 视频」+ 描述 + 数量 → 网格 → 详情。筛选标签与页头标题保持一致。

### 5.3 管理员：发布一件作品

```
登录 → 概览 → 作品 → 新建
  → 填标题/分类/年份/摘要
  → 上传封面（自动记录尺寸）
  → 添加内容块（段落/图片/视频/提示词）
  → 「预览」检查（P1）/ 直接发布
  → 发布校验（必填项）
  → 成功 toast + 「查看前台」
```

失败路径：校验失败 → 定位到第一个错误字段；网络失败 → 保留表单内容 + 重试；slug 冲突 → 就地提示并建议 `-2`。

### 5.4 管理员：调整首页顺序

作品列表按「排序值」排序 → 拖动行或编辑排序值 → 保存 → 首页精选顺序即时更新（revalidate）。

## 6. URL 与 SEO 规则

| 页面 | URL 规则 | title | description | 索引 |
| --- | --- | --- | --- | --- |
| 首页 | `/` | `留白集 · AIGC 作品集` | 站点描述（≤ 120 字） | ✅ |
| 作品总览 | `/works` | `作品 · 留白集` | 「共 N 件作品，涵盖原画、影像、小说等。」 | ✅ |
| 分类 | `/works?type=[slug]` | `[分类名] · 留白集` | 分类描述 | ✅，canonical 自身 |
| 详情 | `/works/[slug]` | `[标题] · 留白集` | 作品摘要 | ✅ |
| 关于 | `/about` | `关于 · 留白集` | 简介首 120 字 | ✅ |
| 后台 | `/admin/**` | `[页面] · 管理后台` | — | ❌ `noindex` |
| 404 | — | `页面未找到 · 留白集` | — | ❌ |

其他规则：

- 分页页 `?page=n`（n ≥ 2）输出 `noindex,follow`，避免重复内容；第 1 页 canonical 不带 `page`。
- 作品 slug 使用小写拉丁字母与连字符；中文标题默认转拼音，可在后台改写。
- 图片文件名不影响 SEO，alt 与 caption 参与语义。
- `sitemap.xml` 只含已发布作品、关于、作品总览与分类；`lastmod` 取 `updatedAt`。

## 8. 响应式断点

| Token | 范围 | 行为 |
| --- | --- | --- |
| `sm` | < 640 | 单列；导航抽屉；目录行改为两行 |
| `md` | 640–1023 | 双列网格；Hero 上下堆叠；隐藏册页线 |
| `lg` | 1024–1279 | 三列网格；导航完整；容器 960 |
| `xl` | 1280–1599 | 设计基准；容器 1200 |
| `2xl` | ≥ 1600 | 容器 1280，留白增大，字号不变 |

后台最低支持 1280；< 1280 出现横向滚动条并在登录页提示「后台建议 1280 px 以上使用」，不阻断操作。

## 9. 状态清单（所有页面共用）

- **加载**：骨架屏，形状与最终内容一致；超过 300 ms 才显示，避免闪烁。
- **空**：一行事实 + 一个动作；不出现插画。
- **错误**：说明发生了什么 + 重试按钮 + 返回入口；不写「哎呀」。
- **无权限**：401 跳登录；403 显示「没有权限执行此操作」。
- **离线/网络失败**：toast + 保留用户输入。
- **图片失败**：显示纸色占位 + 文件名首字母，不显示破图图标。
