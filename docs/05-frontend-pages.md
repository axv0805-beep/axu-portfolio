# 05 · 前台页面设计规格

> 依赖：04 设计系统的 token、组件与文案规范。本文所有尺寸为 1440 px 视口、容器 1200 px 下的值；移动端差异单独标注。
>
> 文案中的 `{{ }}` 为数据占位符，实际渲染取 `site_profile` / `categories` / `works` 字段。

---

## 1. 全局外壳

### 1.1 顶部导航

```
┌──────────────────────────────────────────────────────────────────┐
│ [│] 留白集            首页    作品 ▾    关于              联系     │ 72
└──────────────────────────────────────────────────────────────────┘
```

| 项 | 规格 |
| --- | --- |
| 高度 | 72 px；滚动时保持，底部出现 1 px `--line` |
| 背景 | `rgba(245,241,232,.86)` + `backdrop-filter: blur(12px)` |
| 容器 | 1200 px，左右 40；三栏 `1fr auto 1fr` |
| Logo | 24 px 册页线标记 + 字标 24 px 衬线；整体可点，`aria-label="留白集首页"` |
| 导航 | 14 px，间距 32；当前项 1 px `--accent` 下划线，距文字 8 px |
| 「作品」下拉 | 悬停 120 ms 后展开；宽 300；包含「全部作品」+ 可见分类（名称 + 数量）；`aria-expanded`、方向键可移动、Esc 关闭 |
| 右侧 | 「联系」14 px，`mailto:`；悬停出现下划线 |
| 移动端 < 1024 | 隐藏中间导航；右侧变菜单按钮（24 px，两横线）；打开全屏抽屉 |

**滚动行为**：向下滚动超过 8 px 时加底边线；不隐藏导航，不做滚动缩放。

### 1.2 页脚（深色）

```
┌──────────────────────────────────────────────────────────────────┐
│ 联系                                             目录      站点   │
│ hello@example.com                                AI 原画   首页   │
│ 通常 2 个工作日内回复。                           AI 视频   作品   │
│                                                  ...      关于   │
│ ──────────────────────────────────────────────────────────────── │
│ │ © 2026 留白集                         由 Next.js 构建 · 备案号  │
└──────────────────────────────────────────────────────────────────┘
```

| 项 | 规格 |
| --- | --- |
| 背景 | `--deep`；文字 `--on-deep`；上留白 80，下 32 |
| 左栏 | 眉标「联系」11 mono `--on-deep-2`；邮箱 40 px 衬线，下划线 1 px；说明 13 px |
| 右栏 | 两组链接：目录（最多 6 个分类）、站点（首页/作品/关于）；13 px，行高 32 |
| 底栏 | 上边框 `rgba(244,239,229,.15)`；左版权 12 px；右构建信息与备案号 12 px `--on-deep-2` |
| 签名线 | 版权前 24 px 竖线 + 陶土刻度 |
| 交互 | 链接悬停变白 + 下划线；邮箱点击复制？不，直接 `mailto:` |

页脚在所有前台页面底部出现；后台不出现。

### 1.3 页面容器与册页线

- 容器：`max-width: 1200px; margin-inline: auto; padding-inline: 40px`。
- 装饰册页线：仅首页与详情页，位于容器左边缘外 24 px，`≥ 1280` 显示，`aria-hidden`。
- 页面进入：`opacity 0 → 1` 240 ms，位移不超过 8 px；`prefers-reduced-motion` 时直接显示。

### 2.4 精选作品

| 项 | 规格 |
| --- | --- |
| 区块 | 上 120 / 下 120；无上边框（与目录以留白分隔） |
| 标题行 | 左「精选」40 px 衬线；右「全部作品 · {{count}} 件」13 px 链接 |
| 网格 | 12 栏，gap 24；左 7 栏大卡跨 2 行；右 5 栏两张小卡各 1 行；行高 400 |
| 大卡图 | 填满 700 × 824，`object-fit: cover`，`--r-1` |
| 小卡图 | 填满 476 × 400，`object-fit: cover` |
| 信息 | 图下 16：编号 11 mono `--ink-3`；标题 24 衬线；元信息 13 `--ink-3`（分类 · 年份） |
| 悬停 | 图 `scale(1.02)` 600 ms（容器 overflow hidden）；标题下划线 1 px 展开；箭头不出现 |
| 点击 | 整卡进入 `/works/{{slug}}` |
| 数据 | `featured` 已发布作品按 `sortOrder`，最多 3 张；不足 3 张用最新作品补齐且不重复 |
| 空 | 无作品时隐藏整段 |

**为什么大小卡不等高**：大卡承担「一件代表作」的视觉重量，小卡提供节奏；三张等宽卡片会让首页变成模板。

### 2.5 关于预览

| 项 | 规格 |
| --- | --- |
| 区块 | 上边框 1 px `--line`；上 120 / 下 120；5/7 栏 |
| 左图 | 3:4，`--r-1`，最大宽 380；图注 12 mono |
| 右内容 | 眉标 `关于` 11 mono；标题 40 衬线；正文 17/1.8 最多 2 段、每段 ≤ 80 字；链接「更多关于我」 |
| 数据 | `profile.bio` 首 2 段；为空则整段隐藏 |

### 2.6 首页状态

- **加载**：Hero 文字骨架 + 图片色块；目录 6 行骨架；精选 3 块骨架。骨架不显示文字占位线以外的装饰。
- **无作品**：Hero 正常；目录显示分类但数量为 0；精选区隐藏；关于保留；页脚保留。
- **图片失败**：`--surface-2` + 文件名首字母，图注保留。
- **超长文本**：署名超过 8 字降为 64 px 并允许两行；介绍最多 3 行，超出截断。

### 3.5 分类展示态 `/works?type=ai-painting`

- 页头眉标改为 `COLLECTION / {{nameEn}}`。
- 标题替换为分类名（如「AI 原画」），下方为分类描述（1 行，≤ 40 字）。
- 右侧计数为该分类作品数。
- 筛选栏仍显示全部分类，当前项高亮；点击「全部」回到 `/works`。
- 分类不存在或 `isVisible = false`：返回 404（不静默回退到全部）。
- 分类为空：网格区显示空态「这个分类还没有作品。」+「查看全部作品」。
- `title` / `description` / canonical 用分类字段。

### 3.6 页面状态

- **加载**：页头文字骨架 + 6 个卡片骨架（图 + 两行文字）。
- **无结果**（筛选后）：`--surface` 区块，48 px 册页线 + 「没有符合条件的作品。」+ 「清除筛选」。
- **加载更多**：按钮 loading，禁止重复点击；新卡片淡入 180 ms。
- **错误**：网格区显示「作品没有加载出来。」+「重试」；页头保留。

- 上边框 1 px；上 64 / 下 0；两列，各占 50%。

- 排序依据同列表（同分类优先，再全站）。

### 4.6 状态

- **404**：见第 6 节；不泄露草稿是否存在。
- **内容块未知类型**：跳过并记录警告；不显示「未知块」给访客。
- **图片失败**：占位 + alt 文本；不破坏布局。
- **加载**：标题 + 封面 + 3 段骨架。

## 6. 404 / 错误 / 加载

### 6.1 404

```
┌──────────────────────────────────────────────────────────────────┐
│ [│] 留白集            首页    作品 ▾    关于              联系     │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                          │                                       │
│                          │                                       │
│  404                     这一页不在册子里。                       │
│                          链接可能过期，或者作品已下线。            │
│                                                                  │
│                          [ 返回首页 ]                            │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│  深色页脚                                                         │
└──────────────────────────────────────────────────────────────────┘
```

- 垂直居中，最小高 70vh；`404` 11 mono；标题 40 衬线；说明 15 `--ink-2`；主按钮「返回首页」。
- 不自动跳转；不显示搜索框。

### 6.2 500 / 错误边界

- 标题「页面没有加载出来。」；说明「可以重试，或者回到首页。」；两个操作：主「重试」、次「返回首页」。
- 开发环境显示错误摘要，生产环境不显示堆栈。
- 图片/接口局部失败：区块级提示，不整页崩。

### 6.3 加载

- 路由级 `loading.tsx`：保留导航与页脚，内容区骨架。
- 骨架颜色 `--surface-2`，1.4 s 呼吸；无 shimmer 扫光。
- 超过 300 ms 才显示，避免闪屏。

## 7. 交互与动效清单

| 场景 | 行为 | 时长/缓动 |
| --- | --- | --- |
| 导航下拉 | 淡入 + 上移 4 px | 180 ms `--ease` |
| 导航悬停 | 细线从左展开，当前项保留朱砂短线 | 180 ms |
| 目录行悬停 | 底色出现、名称转陶土色、箭头位移 | 180 ms |
| 作品卡悬停 | 图片 1.04、卡片上移 4 px、箭头位移 | 300 / 180 ms |
| 首屏进入 | 眉标→标题→身份行→介绍→按钮依次淡入上移 | 720 ms，60 ms 递进 |
| 页面滚动 | 区块标题、目录行、作品卡、时间线进入视口时淡入上移 20 px | linear，view() 覆盖 22–36% |
| 首屏图片 | 随页面滚动做 ±28 px 视差 | 滚动时间线 0–800 px |
| 作品封面 | 随视口做 ±12 px 视差，卡片本身 ±6 px，静止时 1.04 倍 | view() 覆盖 0–100% |

| 复制链接 | toast | 2 s |
| 筛选切换 | 立即更新 URL；列表淡出 120 → 淡入 180 | 无布局跳动 |
| 减少动态 | `prefers-reduced-motion: reduce` 时关闭上述动画 | — |

键盘：Tab 顺序 = 导航 → 主内容 → 页脚；下拉用 Enter/Space 打开、方向键移动、Esc 关闭；卡片为链接，Enter 进入；灯箱焦点锁定。
