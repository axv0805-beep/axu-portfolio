| 项目 | 内容 |

| 项目类型 | AIGC 作品集个人网站 + 后台管理 |
| 文档版本 | v0.1（待评审） |
| 日期 | 2026-11-09 |

> 本文档中的「留白集」是项目代号与默认站点名，不是最终品牌。站点名、署名、简介、头像均可在后台「个人资料」中修改，前台不得出现写死的姓名或文案。

---

## 1. 背景

创作者使用生成式模型产出原画、影像、小说、音乐、应用与智能体等多媒介作品。这些作品目前散落在网盘、社交平台与本地文件夹中，缺少一个能长期维护、能讲清「作品 + 制作过程」的独立陈列空间。

同时，作品集的内容会持续增加，必须有一个不依赖开发者的后台：新增作品、调整分类、替换封面、修改个人介绍，都应当由创作者自己完成。

项目要求严格遵循 SDD：先产出可评审的设计文档，再进入编码；文档要足够具体，使后续开发者能在不改变视觉语言的前提下扩展与迁移。

## 2. 目标

1. **一个安静的作品展厅**：访客在 10 秒内理解「这是谁、做什么、去哪里看作品」，并愿意点开至少一件作品。
2. **一个可自助运营的后台**：非技术用户可在 3 分钟内完成一次「新建作品 → 上传封面 → 发布」。
3. **一套可延续的设计资产**：设计令牌、组件规格、页面规格、数据与接口约定齐全，后续新增媒介类型不需要重做视觉。

## 3. 目标用户

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 访客 V | 招聘方、合作方、同好，通过链接或搜索进入 | 快速判断创作者水平与方向；顺畅浏览作品大图；了解创作方法 |
| 创作者 O | 站点所有者，唯一管理员 | 低摩擦维护作品；控制展示顺序与显隐；不改代码就能调整站点 |
| 开发者 D | 后续接手或扩展的人 | 文档可信、结构清晰、改动有边界 |

## 4. 范围

### 4.1 P0（本期必须）

- 前台：首页、作品总览、作品详情、关于、404/错误/加载态。
- 展示类型：AI 原画、AI 视频、AI 小说为必做；AI 音乐、AI 应用、AI 智能体为同构扩展，后台可自建。
- 后台：登录、概览、作品增删改查、分类管理、图片上传、个人资料、站点设置。
- 作品内容支持图文混排、视频嵌入、音频、提示词/参数、外链。
- 响应式：≥ 1280 px 完整；1024–1279 px 可用；< 1024 px 不破版即可（不作为验收重点）。
- SEO：标题/描述/OG/站点地图；图片 alt 必填。
- 交付：全部设计文档、各界面截图、源码压缩包。

### 4.2 P1（本期可选，排期允许再做）

- 媒体库（统一管理已上传文件）。
- 作品草稿自动保存。
- 首页「正在做」状态条。
- 访问统计（不含第三方 Cookie；首版仅预留 `viewCount` 字段，不做报表）。

### 4.3 不做（Out of Scope）

- 用户注册、评论、点赞、收藏、支付。
- 多管理员与细粒度权限（数据模型预留）。
- 移动端 App / 小程序。
- 站内 AI 生成功能（本站只陈列作品，不调用生成模型）。
- 复杂 CMS 工作流（多人审核、定时发布）。
- 暗色主题（只预留 token 映射，不做切换；见 12 ADR-012）。

## 6. 成功标准

| 维度 | 标准 | 验证方式 |
| --- | --- | --- |
| 可用性 | 新访客 10 秒内说出站点主题与至少 2 个作品类型 | 5 人快速测试 |
| 性能 | 首屏 LCP ≤ 2.0 s（4G 模拟）、CLS ≤ 0.05、INP ≤ 200 ms | Lighthouse / WebPageTest |
| 质量 | 公开页 Lighthouse Performance ≥ 90、Accessibility ≥ 95 | Lighthouse CI |
| 后台效率 | 熟练用户 3 分钟内完成「新建 → 上传 → 发布」 | 计时测试 |
| 可维护性 | 新增一个作品分类 = 后台操作，0 行代码；新增一种内容块 ≤ 4 个文件 | 按 11 号文档演练 |
| 视觉一致性 | 所有颜色/字号/间距来自 token；无硬编码 hex | `zh_design_lint` + Code Review |
| 内容完整 | 每件作品有封面、alt、分类、年份、至少 1 个内容块 | 发布校验 |

## 7. 约束与假设

- **技术约束**：单仓全栈、单进程可运行；不依赖付费 SaaS；本地文件存储优先，可替换。
- **内容约束**：中文为主，允许英文标题与专有名词；所有文案可在后台修改。
- **版权约束**：不复制 Claude 的商标、字体与插画；只借用「暖纸底 + 衬线标题 + 克制的陶土色」这一气质。
- **运行约束**：Node.js 22 LTS、现代浏览器（Chrome/Edge/Safari 最近两个大版本）。
- **假设**：只有一位管理员；作品量 < 500；单张图片 ≤ 10 MB；视频以 B 站/YouTube 外链为主。

## 8. 术语

| 术语 | 含义 |
| --- | --- |
| 展示页 / 分类页 | 按媒介划分的作品集合页，如「AI 原画」；由 `categories` 驱动 |
| 作品 | 一条可独立访问的内容，拥有封面、元信息与内容块 |
| 内容块 Block | 作品正文的最小单元：段落、图片、视频、提示词等 |
| 重点作品 Featured | 首页「精选」区展示的作品，最多 3 件 |
| 册页线 | 本站唯一签名视觉元素：1 px 竖线 + 短刻度，一屏最多 3 处（见 04 文档） |
| 发布 | 作品状态从 `draft` 变为 `published`，前台可见 |
