# 06 · 后台管理设计规格

> 后台与前台共用 04 设计系统的颜色、字体、间距与组件，但信息密度更高：侧栏 240 px、顶栏 64 px、内容区内边距 32 px、表格行高 44–56 px。
>
> 后台不做营销式欢迎语；页面标题即对象名（「作品」「分类」）。

### 1.2 导航结构

| 顺序 | 名称 | 路由 | 图标（Lucide） |
| --- | --- | --- | --- |
| 1 | 概览 | `/admin` | `layout-dashboard` |
| 2 | 作品 | `/admin/works` | `images` |
| 3 | 分类 | `/admin/categories` | `folder` |
| 4 | 媒体（P1） | `/admin/media` | `hard-drive` |
| 5 | 个人资料 | `/admin/profile` | `user` |
| 6 | 站点设置 | `/admin/settings` | `settings` |

面包屑规则：`概览`；`作品 / 列表`；`作品 / 编辑`；`作品 / 新建`；`分类`；`个人资料`；`站点设置`。当前页不带链接。

### 1.3 全局反馈

- 写操作成功：右上 toast，`--deep` 底，2.4 s；失败：toast + 字段级错误。
- 未保存离开：浏览器 `beforeunload` + 站内路由确认弹窗「有未保存的修改，确定离开？」
- 网络失败：表单内容保留；顶部条「保存失败，请检查网络后重试。」；重试按钮。
- 会话过期：任意请求 401 → 跳登录页，登录后回到当前页；表单内容在 sessionStorage 暂存 10 分钟。

### 4.2 交互

- 点击行标题或「编辑」→ `/admin/works/[id]`。
- 复选框：单选/全选当前页；选中行底色 `--accent-soft`。
- 批量发布：已发布项跳过，toast「已发布 2 件，1 件已是发布状态」。
- 批量删除：弹窗输入「删除」确认；显示数量；删除后刷新列表。
- 单条删除：弹窗「删除《潮汐》？此操作不可撤销。」+ 取消/删除（danger）。
- 所有写操作后刷新 RSC 数据，不整页 reload。
- 键盘：`Esc` 清除批量选择；`/` 聚焦搜索（P1）。

### 5.2 顶栏

| 项 | 规格 |
| --- | --- |
| 左 | 返回箭头 20 + 「新建作品」/当前标题（截断 30 字）；未保存时标题后加 `·` |
| 右 | 自动保存状态 12 `--ink-3`（保存中… / 已保存 14:32 / 有未保存修改）；「预览」secondary（P1）；「保存草稿」secondary；「发布」/「更新」primary |
| sticky | top 0；背景纸色 95% + blur；底部 1 px 线；z 30 |
| 发布按钮 | 草稿时「发布」；已发布时「更新」；有校验错误时点击滚动到第一个错误并 toast |

### 5.3 主表单

| 字段 | 控件 | 规则 | 错误文案 |
| --- | --- | --- | --- |
| 标题 | 无边框大输入，32 衬线，占位「输入作品标题…」 | 必填，2–80 字 | 标题不能为空 / 标题不能超过 80 字 |
| Slug | 前缀 `/works/` + 输入框 13 mono | 必填，2–80，`^[a-z0-9]+(?:-[a-z0-9]+)*$`；失焦查重 | 只能用小写字母、数字与连字符 / 这个链接已被使用 |
| 摘要 | textarea 2 行 | 必填，≤ 120 字 | 摘要不能为空 / 摘要不能超过 120 字 |
| 封面 | 4:5 上传框 + 预览 | 必填；≤ 10 MB；JPG/PNG/WebP/AVIF | 请上传封面 / 图片不能超过 10 MB |
| 封面 Alt | 输入框 | 必填，≤ 120 字 | 请描述封面内容，供读屏使用 |
| 精选封面 | 3:2 或 16:9 上传框 + 预览 | 可选；仅首页精选使用，不影响列表与详情 | 建议 3:2；未上传时回退主封面 |
| 内容 | 块编辑器 | 发布时 ≥ 1 块 | 至少添加一个内容块 |

Slug 生成：标题输入后 500 ms、且 slug 未被手动修改时，自动转拼音生成；冲突时追加 `-2`、`-3`；用户手动改过后不再自动覆盖。输入框右侧状态：`可用`（成功色）/ `检查中…` / `已被使用`（危险色）。

| --- | --- | --- |
| 发布 | 状态 | 只读展示当前状态 + 说明「草稿仅自己可见」；状态切换由底部按钮完成 |
| 发布 | 发布时间 | 已发布显示时间；草稿为空；支持「立即」/选择日期（P1 定时） |

| 发布 | 排序 | 数字 0–999，默认 0；说明「数字越小越靠前」 |

### 5.5 封面上传

- 空态：4:5 虚线框 200 × 250；中央 `image-plus` 20 + 「拖拽或点击上传」13；下方格式说明 11。
- 上传中：进度条 + 百分比；禁用移除。
- 已上传：200 × 250 预览；悬停出现「替换」「移除」；下方显示 `1200 × 1500 · 842 KB`。
- 移除：确认「移除封面？保存后前台将不再显示。」（发布状态下不允许保存空封面）。
- 拖拽到框外不触发上传；支持粘贴图片（P1）。

| 分组 | 块 |
| --- | --- |
| 文本 | 段落、标题、引用、提示词 |
| 媒体 | 图片、图集、视频、音频 |
| 其他 | 链接、分隔线 |

**块卡片通用**：

┌──────────────────────────────────────────────┐
│ ⠿  段落                               ↑ ↓ ⋯ │
│ ┌──────────────────────────────────────────┐ │

- 卡片：1 px `--line`，`--surface` 底，`--r-2`，内边距 16；聚焦时左侧 2 px `--accent`。
- 头部：拖拽手柄 16、类型名 11 mono、上移/下移/更多（删除、复制）；折叠按钮在类型名左侧。
- 拖拽：HTML5 拖拽或 dnd-kit；拖动时半透明 + 插入线；键盘用「上移/下移」菜单项。
- 新块插入到当前块之后，并自动聚焦第一个输入。

| 块 | 字段 | 说明 |
| --- | --- | --- |

| 图集 | 2–6 张图片 + 布局（2/3 列） | 每张可填图注；拖拽排序 |
| 视频 | 来源（B 站/YouTube/文件）+ URL/上传 + 封面 + 图注 | URL 域名白名单；文件 ≤ 100 MB |
| 音频 | 外链 URL + 标题 + 封面（可选） | 首版不提供音频上传；URL 仅 https |

| 分隔线 | 无 | 预览一条 1 px 线 |

### 5.7 自动保存与冲突

- 触发：停止输入 3 s，或每 30 s 有改动；仅已创建的作品自动保存；新建页首次保存需点击「保存草稿」。
- 状态：`有未保存修改` → `保存中…` → `已保存 14:32`；失败 → `保存失败，点击重试`。
- 冲突：PATCH 带 `updatedAt`；409 时弹窗「这件作品在另一个窗口被修改了。」提供「加载最新版本」/「覆盖保存」；覆盖需二次确认。
- 离开：有未保存修改时，站内跳转与关闭标签页均拦截。
- 发布：先保存，再校验，再 PATCH 状态；成功后 toast「已发布」+「查看前台」链接。

### 5.8 校验与错误

- 字段错误就地显示，红色边框 + 12 px 文案；顶部汇总「还有 3 项需要处理」+ 可点击定位。
- 发布校验顺序：标题 → slug → 分类 → 封面 → 封面 alt → 摘要 → 年份 → 内容块。
- 作品 SEO 标题与描述不单独维护：前台用作品标题、摘要自动生成；需要更精确的 SEO 时改标题与摘要。
- 服务端错误映射到字段；未知错误显示 toast。

## 10. 账号安全 `/admin/account`

- 「修改密码」表单：当前密码、新密码、确认新密码；新密码 ≥ 10 位，需包含字母与数字。
- 强度提示：弱/中/强；不强制特殊字符。
- 提交成功：toast「密码已更新」；当前会话保留，其他会话失效。
- 错误：「当前密码不对。」「两次输入不一致。」「新密码至少 10 位。」
- 「退出登录」：确认后清除会话，跳登录页。

## 13. 后台可访问性

- 所有表单 label 与控件关联；错误用 `aria-describedby`。
- 表格有 `<caption class="sr-only">`；排序按钮带 `aria-sort`。
- 拖拽排序提供键盘替代（上移/下移）。
- 弹窗焦点锁定、Esc 关闭、关闭后焦点归还。
- 状态不只靠颜色：发布/草稿均带文字与图标。
- 对比度：后台文字使用 `--ink` / `--ink-2`，`--ink-3` 仅用于辅助信息且不小于 12 px。
