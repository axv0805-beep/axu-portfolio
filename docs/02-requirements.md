# 02 · 需求规格说明书

版本 v0.1 · 2026-11-09 · 状态：待评审

## 1. 角色与权限

| 能力 | 访客（未登录） | 管理员（已登录） |
| --- | --- | --- |
| 浏览已发布作品 / 分类 / 关于 | ✅ | ✅ |
| 访问草稿或预览链接 | ❌ | ✅ |
| 登录后台 | ❌ | ✅ |
| 作品 / 分类 / 资料 / 设置写操作 | ❌ | ✅ |
| 上传媒体 | ❌ | ✅ |

规则：

- 除 `/admin/login` 外，所有 `/admin/**` 与 `/api/admin/**` 必须登录；未登录访问页面 302 到登录页并带 `?next=`，未登录访问 API 返回 `401 UNAUTHORIZED`。
- 前台只查询 `status = published` 且 `published_at <= now()` 的作品；草稿即使知道 slug 也返回 404。
- 单管理员模型；用户表保留 `role` 字段，为后续多角色预留。

## 4. 业务规则

| ID | 规则 |
| --- | --- |
| BR-01 | `works.slug` 全局唯一，仅允许小写字母、数字、连字符，长度 2–80；为空时由标题生成（中文转拼音），冲突追加 `-2` |
| BR-02 | 发布必填：标题、slug、分类、封面与封面 alt、摘要、年份、至少 1 个内容块；缺项时按钮 disabled 并列出缺失项 |
| BR-03 | 删除分类前必须无关联作品；否则提示「该分类下还有 N 件作品」 |
| BR-04 | 作品排序：`sortOrder` 升序，相同则 `publishedAt` 降序 |
| BR-05 | 分类排序：`sortOrder` 升序；首页目录最多显示 8 个 |
| BR-06 | 封面比例建议 4:5；上传非 4:5 时按 `object-fit: cover` 裁切，不强制裁剪 |
| BR-07 | 图片单张 ≤ 10 MB，格式 JPEG/PNG/WebP/AVIF；禁止 SVG 上传（XSS 风险）；视频单文件 ≤ 100 MB，优先外链 |
| BR-08 | 标题 ≤ 80 字，摘要 ≤ 120 字，alt ≤ 120 字，标签 ≤ 8 个，工具 ≤ 8 个 |
| BR-09 | 所有富文本按白名单清洗；禁止 `script`、`iframe`（视频 iframe 由系统按白名单域名生成） |
| BR-10 | 访客不可见草稿；预览使用带签名的临时链接（P1） |
| BR-11 | 时间统一存 UTC，展示按 `Asia/Shanghai` |
| BR-12 | 删除作品为硬删除（P0）；回收站为 P1 |

## 6. 验收标准（Given / When / Then）

**AC-01 首页**
- Given 数据库有 6 个可见分类、至少 3 件精选作品
- When 访客打开 `/`
- Then 首屏出现署名、身份行、一句介绍、头像；目录显示 6 行；精选区显示 ≥ 3 件作品；页脚显示邮箱

**AC-02 目录**
- Given 分类「AI 原画」有 8 件已发布作品
- When 点击首页目录第 01 行
- Then 进入 `/works?type=ai-painting`，列表显示 8 件，筛选标签「原画」高亮，计数为 8

**AC-03 精选补齐**
- Given 只有 2 件 `featured` 作品
- When 打开首页
- Then 精选区显示 2 件精选 + 最新作品补齐至 3 件，不重复

**AC-04 筛选与分页**
- Given 共 30 件已发布作品
- When 打开 `/works?page=2`
- Then 显示第 13–24 件；URL 可直接分享并还原相同结果；浏览器后退恢复上一页

**AC-05 详情**
- Given 一件含图片、视频、提示词块的作品
- When 打开详情
- Then 所有块按顺序渲染；提示词可展开/复制；上一件/下一件可点击；未知 slug 返回定制 404

**AC-06 关于**
- Given 后台填写了简介、工具、时间线与社交链接
- When 打开 `/about`
- Then 内容按「简介 → 工具 → 时间线 → 联系」顺序展示；Markdown 链接安全可点

**AC-07 空态**
- Given 某分类下没有已发布作品
- When 打开该分类
- Then 显示「这个分类还没有作品。」+「查看全部作品」按钮，不显示空白网格

**AC-08 SEO**
- Given 作品「潮汐」
- When 查看源代码或分享链接
- Then `<title>` 为「潮汐 · 留白集」；OG 图使用封面；JSON-LD 类型 `CreativeWork`；sitemap 含该 URL

**AC-09 图片**
- Given 上传 4000×5000 的 JPEG
- When 前台以 600 px 宽展示
- Then 实际下载 ≤ 1200 px 宽的 WebP/AVIF；无布局抖动；alt 来自后台

**AC-10 登录**
- Given 未登录
- When 访问 `/admin/works`
- Then 302 到 `/admin/login?next=%2Fadmin%2Fworks`；登录后回到原页面
- Given 连续 5 次密码错误
- When 第 6 次提交
- Then 提示「尝试次数过多，请 15 分钟后再试」，返回 429

**AC-11 概览**
- Given 38 件已发布、4 件草稿、6 个分类
- When 打开 `/admin`
- Then 四个数字分别为 42 / 38 / 4 / 6；最近编辑按更新时间倒序显示 5 条

**AC-12 作品列表**
- Given 42 件作品
- When 输入关键词「潮」并选择「草稿」
- Then 只显示标题或摘要含「潮」且状态为草稿的作品；清空筛选后恢复全量

**AC-13 新建并发布**
- Given 管理员在 `/admin/works/new`
- When 填写标题、分类、年份、摘要，上传封面，添加 1 个段落块，点击「发布」
- Then 作品创建成功，状态 `published`，出现在前台对应分类；后台列表可见；操作有 toast 反馈

**AC-14 批量**
- Given 勾选 3 件作品
- When 选择「转为草稿」
- Then 3 件状态变为草稿，前台立即不可见；toast 显示「已更新 3 件作品」

**AC-15 分类**
- Given 分类「AI 音乐」下有 2 件作品
- When 点击删除
- Then 弹窗提示「该分类下还有 2 件作品，先移动或删除后再试」，不允许删除

**AC-16 上传**
- Given 选择 12 MB 的 PNG
- When 上传
- Then 前端立即提示「图片不能超过 10 MB」，不发请求

**AC-17 资料与设置**
- Given 修改站点名与首页介绍
- When 保存并刷新前台
- Then 首页、导航、页脚、`<title>` 同步更新，无需重启

**AC-18 改密**
- Given 已登录
- When 旧密码正确、新密码 12 位并确认
- Then 提示成功，当前会话保留，其他设备会话失效

## 7. 边界与非目标

- 不做站内搜索全文检索（P0 只做标题搜索）；作品量 > 200 时再评估 SQLite FTS。
- 不做多语言；URL 不带语言前缀。
- 不做在线预览草稿（P1）；P0 草稿仅后台可见。
- 不做图片裁剪器；封面按容器比例裁切，后台显示裁切预览。
- 不做实时协作编辑；同一时间只允许一个管理员编辑同一作品（乐观锁 `updatedAt`）。

## 8. 风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 中文衬线字体在不同系统差异大 | 首屏观感受损 | 标题使用系统宋体栈；可选自带子集字体，失败回退 |
| 视频文件过大导致部署困难 | 上传慢/磁盘满 | 默认外链 B 站/YouTube；本地上传限制 100 MB |
| 作品图片多导致首屏慢 | LCP 超标 | 封面统一 4:5、CDN/缓存头、`next/image`、懒加载 |
| 单管理员忘记密码 | 无法维护 | `pnpm reset-password` 脚本 + 备份说明 |
| 内容块结构演进 | 旧内容渲染失败 | 块 schema 带 `version`；渲染器对未知类型降级为提示 |
